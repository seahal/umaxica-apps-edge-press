# Public Information Surfaces

Umaxica Press operates twelve public, read-only content Workers:
`{app,com,org}/{docs,help,info,news}`. Each cell runs TanStack Start and serves one audience and surface. Rails remains the authority for persistent content, publication state, management operations, and authorization.

## Workspace matrix

| Audience | Docs       | Help       | Info       | News       |
| -------- | ---------- | ---------- | ---------- | ---------- |
| `app`    | `app/docs` | `app/help` | `app/info` | `app/news` |
| `com`    | `com/docs` | `com/help` | `com/info` | `com/news` |
| `org`    | `org/docs` | `org/help` | `org/info` | `org/news` |

## Public boundary

The cells issue server-side GET requests to Rails through the Cloudflare Workers VPC binding. They do not make browser-side Rails requests, forward browser session cookies, carry user-scoped secrets, or expose a generic Rails proxy. Editing and publishing remain on the Rails staff origin; public pages link there by `public_id`, and Rails checks authorization after navigation.

The language prefix is mandatory (`ja` or `en`). `/` negotiates a language and redirects. `/{lang}/` is the surface home; `/{lang}/about/` is generated by Edge. Entries use page pagination at `/{lang}/entries/` and `/{lang}/entries/page/{N}/`; individual entries use `/{lang}/entries/{public_id}/`. Edge forwards the page number to Rails and does not calculate SQL offsets. Search uses the local `SearchSource` seam.

Only individual entry pages use the current public cache policy. The home, collection, search, and about routes are rendered per request. See [Caching and ISR](caching-and-isr.md) for the deferred cache work.

## Implementation and checks

Every unit is standalone and owns its Vite, TypeScript, lint, format, test, and Knip configuration. `tools/workers-manifest.json` lists these twelve cells as VPC-backed TanStack Workers; `pnpm run check:workers` checks their environment tiers, VPC bindings, rate limits, observability, cache policy, and tracked public assets. `test/publishing-cells.test.ts` checks the cell matrix and parity of shared files.

The accepted boundaries are recorded in [ADR 019](../adr/019-edge-parallel-contract-boundaries.md). Earlier Astro design records remain historical; the current cells use Vite+ with TanStack Start.
